# Shop Fractions

Offline flashcards for fraction ↔ decimal conversions, machinist style.
Data from *Machine Fundamentals* p.412.

**Use it:** open the site on your phone → browser menu → **Add to Home Screen**. Works offline after the first visit.

## Modes
- **Fraction → Decimal** — type the decimal. `.625`, `0.625`, `.6250`, `0.6250` all count. `.6` doesn't: read it to x.xxx or x.xxxx.
- **Decimal → Fraction** — multiple choice against the nearest neighbors.
- **Mixed** — coin flip per card.

## Editing
- Card data lives in `cards.js`.
- **After changing any file, bump `VERSION` in `sw.js`**, or installed phones keep the old cached copy.
